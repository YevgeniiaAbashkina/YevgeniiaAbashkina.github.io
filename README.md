# Yevheniia Abashkina – Portfolio

Static portfolio website (HTML, CSS, JavaScript – no build step), bilingual DE / EN.

**Live:** https://yevgeniiaabashkina.github.io/

## Structure

| Path | Content |
|---|---|
| `index.html` | Home: intro, web development, UI/UX design, AI visuals, contact |
| `web-development.html` | Technical implementation & web development projects |
| `concept-design.html` | Concept, design & development projects |
| `legal-notice.html`, `privacy.html` | Legal notice & privacy policy |
| `css/style.css` | All styles |
| `js/main.js` | Language switch, navigation, carousel, animations |
| `assets/` | Fonts (self-hosted), icons, images |

## Local preview

Open `index.html` in a browser – no server or build required.
